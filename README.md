# Financial Accounting System

This project is a web-based financial accounting system built with a Python Flask backend and a yet-to-be-determined frontend.

## Features

The system will be developed incrementally, with the following features planned:

1.  **General Ledger System (Voucher Management)**
    - Add/save accounting vouchers.
    - Automatic numbering and date setting.
    - Subject selection from a chart of accounts.
    - Automatic balancing validation for debit and credit amounts.

2.  **Reporting System**
    - Automatic generation of balance sheets, income statements, and cash flow statements.
    - Charts for fund balances and income/expense trends.
    - Accounts receivable/payable aging analysis.

3.  **Fund Management**
    - Calculation of bank deposits, cash on hand, and available funds.
    - Predictive fund model (short-term receivables and payables analysis).

4.  **Basic Data Maintenance**
    - Management of the chart of accounts.
    - Customer/supplier management.
    - Personnel/project classification.

5.  **Accounting Period and Set Management**
    - Management of multiple accounting sets.
    - Setting of accounting periods.

## Technology Stack

-   **Backend:** Python (Flask)
-   **Database:** SQLite (initially), with the option to move to MySQL or PostgreSQL.
-   **Frontend:** To be determined (likely Vue.js or React).
